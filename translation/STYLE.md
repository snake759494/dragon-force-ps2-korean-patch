# 드래곤 포스 한글화 번역 지침

게임: 「드래곤 포스」(세가 새턴 원작, PS2 세가 에이지스 2500 Vol.18). 대륙 레젠드라에서 8개 나라의 군주가 패권을 다투다가, 부활하려는 사신 마드룩에 맞서는 성룡의 팔전사의 이야기. 판타지 전략 RPG.

## 절대 규칙
- **외부 기계번역(웹 번역기·API·라이브러리) 사용 금지.** 직접 읽고 직접 번역한다.
- 고유명사는 `translation/glossary.json`(일본어→한국어)을 **반드시** 따른다. 목록에 없는 고유명사는 같은 원칙(장음 생략, 외래어 표기법)으로 음역하고 작업 내내 통일한다.
- 태그는 글자 그대로 보존한다: `⟦V 09⟧`, `⟦S 0F⟧`, `⟦09⟧` 같은 `⟦…⟧`, `%s` `%d` `%3d` `%02d` 같은 서식, 역슬래시 명령(`\p`, `\e`, `\n`), `&003` 같은 `&숫자3자리`, 함성의 `@`.
  - `⟦V 00⟧`=말하는 사람 자기 이름, `⟦V 01⟧`=나라/군 이름, `⟦V 02⟧`=플레이어 군주 이름, `⟦V 05⟧` `⟦V 06⟧` `⟦V 09⟧`=장수 이름, `⟦V 07⟧`=숫자, `⟦V 0F⟧`=아이템 이름.
  - 변수 뒤에는 받침에 따라 달라지는 조사(이/가, 은/는, 을/를, 와/과, 으로/로)를 바로 붙이지 말 것. "⟦V 09⟧ 님", "⟦V 0F⟧(을)를" 대신 문장을 바꿔 피하는 것이 가장 좋다. 예: 「⟦V 0F⟧を見つけたぞ！」→ "찾았다! ⟦V 0F⟧다!" 또는 "⟦V 0F⟧, 찾았다!". 「⟦V 06⟧が戦死いたしました」→ "⟦V 06⟧ 님께서 전사하셨습니다…" / "장수 ⟦V 06⟧, 전사했습니다." 처럼.
  - `⟦S 0F⟧・・・・・・⟦S 00⟧` 같은 속도 태그 사이의 점선은 그대로 두거나 `......`로.
- 쓸 수 있는 문자: 한글, ASCII(영숫자·공백·`.,!?'"()~-:;/%`), 일본어 전각 기호 중 `「」『』（）！？・…♪★☆○●◎△▲▽▼□■◇◆→←↑↓` 정도. **한자·가나는 쓰지 말 것.** `·`(가운뎃점) 대신 `・`.
- 말줄임표는 `...`(반각 마침표 셋). 원문의 `・・・`도 `...`로.
- 문장부호는 반각 `.,!?`를 기본으로(공간 절약). 공백은 반각 공백.

## 분류별 규칙 (단위의 `cat`)
- **dlg (대사)**: 한 단위 = 한 사람이 이어서 하는 말(여러 페이지). 원문의 빈 줄은 원래 페이지 경계. 번역문은 줄바꿈 신경 쓰지 말고 자연스럽게 써도 된다(빌드에서 한 줄 13자·2줄씩 자동으로 다시 나눔). 장면 전환처럼 꼭 페이지를 나누고 싶은 곳만 빈 줄을 넣는다. 분량은 원문과 비슷하게(원문 글자 수의 1.2배 이내), 늘어지는 의역 금지.
- **shout (전투 함성)**: 짧고 힘 있게. `\n`=줄, 빈 줄=페이지. 한 줄 13자 이내.
- **pool (시스템·메뉴 문자열)**: 메뉴 칸이 고정되어 있으므로 **한국어 폭이 원문 폭 이하**가 되게(한글 1자 = 일본어 전각 1자, 반각 문자 = 0.5자). 줄바꿈 `\n`의 수와 위치를 원문과 같게 유지. 앞뒤 공백은 신경 쓰지 말 것(빌드에서 원래 폭으로 가운데 맞춤). 인물·아이템·성 이름은 용어집 그대로. 영어로 된 디버그 문자열은 오지 않는다.
- **nation (국가 소개문)**: 원문과 **같은 줄 수**, 각 줄 **한글 10자 이내**(반각은 0.5자). 문단 첫 줄은 원문처럼 앞에 반각 공백 2칸. 줄 끝에서 낱말이 끊기지 않게 자연스럽게 나눈다.
- **zukan (도감)**: 원문의 줄 구조(빈 줄, 앞의 전각 공백 들여쓰기 `　`)를 유지. 한 줄 한글 24자 이내(넘으면 빌드가 다시 나눔).
- **goddess**: `&002` `&003` `&006` `&010` 코드와 `#`(줄바꿈)를 원문 위치 그대로 보존.

## 말투
- 원작의 캐릭터성을 살린다. 왕·장군은 위엄 있게, 병사·도적은 거칠게, 노인은 노인 말투.
- 1인칭: ぼく/僕→나, 俺/おれ/オレ→나(거친 말투), わたし/私→나/저(상대에 맞게), 予→짐, 拙者→소인, わし→나(노인 말투), あたし→나(여성 말투), おいら/オイラ→나(어리숙한 말투), 我→나/우리.
- 존칭: ～様→～ 님(군주에게는 "웨인 님", 신하가 왕을 부를 때 "폐하"도 가능), ～殿→～ 공/～ 님, ～さん→～ 씨/～ 님.
- 군주(웨인 등)가 신하에게: 반말(해라/해체). 신하가 군주에게: 합쇼체/하오체. 일본어의 말투 차이(ですな、ぞ、じゃ 등)를 한국어 어미로 살린다.

## 출력 형식
- 입력: `translation/jobs/jNNN.json` 의 `units` 배열(각각 `id`, `cat`, `ctx`(출처·말하는 사람), `jp`).
- 출력: `translation/out/jNNN.json` = `{"id": "한국어 번역", ...}` (UTF-8 JSON 객체, 모든 id 포함, ensure_ascii=False).
- 같은 작업 안의 단위는 대화 순서대로 놓여 있으니 앞뒤 문맥을 보고 번역한다.

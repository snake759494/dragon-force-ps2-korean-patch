# 기술 설명

## 전체 구조
- PS2 판은 PS2 쪽 계층 위에서 **새턴 SH-2 프로그램을 그대로 실행**한다. 문자열·그림 대부분은 루트의 `DATA.0` 아카이브에서 읽는다.
- `DATA.0`: 앞 0xa000 바이트가 엔트리 오프셋표(엔트리 8,868개). 수정한 엔트리를 순서대로 다시 이어 붙이고(0x800 정렬), ISO9660 과 UDF 디렉터리의 크기·위치를 갱신한다(`tools/data0.py`, `tools/isopatch.py`, `tools/build.py`). ISO 전체 크기는 원본과 같다.
- 엔트리 17 은 새턴 메인 프로그램 이미지로 부팅 때 메모리에 올라간다(이 부분의 변경은 원본 세이브 스테이트로는 확인할 수 없다).

## 글꼴
- 엔트리 67: JIS 94×94 순서, 32×32 2bpp 글리프 두 개를 4bpp 한 칸에 겹친 구조. JIS 16구(SJIS 0x889F~)부터 한글 2,351자를 배정(`tools/hangul.py`, `tools/build_font.py`).
- 16px 작은 글꼴(무장 정보의 직업·소속 등 반각 칸)은 같은 코드의 다른 위치(0x8d3000 + 코드×64 에서 읽음)를 쓴다. 작은 글꼴에 쓰이는 음절을 0x889F~0x89E2 에 먼저 배정하고, 엔트리 67 안 해당 위치에 15px 글리프를 그렸다.
- 원본과 가장 비슷한 나눔스퀘어 네오 ExtraBold 사용.

## 텍스트
- 메시지 뱅크(770·1032·1536·1552 계열, 국가별 8개): 키표 + BE 오프셋표 + 본문을 다시 쓴다(`tools/bank.py`, `tools/sources.py`).
- 1544 계열(역슬래시 명령 `\u` `\l` `\p` `\w` `\e`), 1560 전투 함성(`#` 줄, `$` 쪽), 1561 여신, 1563·1564 도감(포인터표).
- 1562 시스템 문자열 풀(3,205개): SH-2 코드가 1535 의 원문으로 찾아 1562 값으로 바꿔 쓰므로 1562 만 번역한다. 국가 소개문은 원본 줄 칸 크기에 맞춰 낱말 단위로 다시 채운다.
- ELF·READY/APPLI/OPEN.BIN 안의 문자열은 원래 칸(정렬 여유 포함) 안에서 제자리 교체.
- 대사는 한 줄 13자·2줄 단위로 자동 줄바꿈(`tools/wrap.py`). 변수 뒤 받침 의존 어미는 받침과 무관한 형태로 고친다(`fix_josa`).

## 그림
- 군주 소개·대륙 지도·병법 해설: JPEG(엔트리 70·76). OpenCV 인페인팅으로 글자를 지우고 한글 합성, 원래 크기 이하로 재압축(`tools/images.py`). 엔트리 74 는 타이틀 배경이라 건드리지 않는다.
- 전투 VS 화면 이름·라벨: 엔트리 769 = 새턴 VDP1 4bpp 스프라이트(상위 니블 먼저, 높이 16, 폭 8의 배수)를 이어 붙인 것. 장수 150·나라 8·병종 10·숫자·軍(0x12180)·師団(0x12200)·雇用兵団(0x123c0)·地形効果(0x13ba0, 폭 88). 전투 중에는 엔트리 770~777 의 0x7680 에 있는 사본을 쓰므로 둘 다 고친다(`tools/spr769.py`).
- 진형선택·일기토 제목: 엔트리 17 안의 4bpp 스프라이트(陣形選択 0x14af19 96×23, 一騎討ち 0x14a55e 136×31), 엔트리 780 에 사본. 색 번호는 행마다 위→아래 그라데이션(f→5), 2 = 테두리, 3 = 그림자(`tools/titles.py`).
  - 찾은 방법: 세이브 스테이트 EE 메모리 0xbaa000 의 VDP1 프레임버퍼에서 제목 픽셀(색 뱅크 0xd0 + 4bpp 번호)을 뽑아 니블 패턴으로 데이터 전체를 검색.

## 동영상
- `M1/*.PSS` 는 MPEG-2 프로그램 스트림(음성은 0xBD 패킷, SShd/SSbd 헤더 48kHz PCM). 다시 인코딩하면 그림 바이트 위치가 원본과 어긋나 PS2 재생기가 멈추는 문제가 있어 이번 판에서는 손대지 않았다.
